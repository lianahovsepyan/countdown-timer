# Countdown Timer

A simple Python-based terminal countdown timer created for TUMO Labs.

## Requirements & Features
- Built with pure Python using standard libraries (`time`)
- Uses variables, functions, loops (`while`), conditional statements, and strings
- Delays countdown by 1 second on each line using `time.sleep(1)`

## How to Run
1. Run the Python script:
   python timer.py
2. Enter the duration in seconds.
